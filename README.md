# Happy Tails Pet Shop

**Pet Shop** is a Flask-based web application that showcases a fictional pet store, *Happy Tails Pet Shop*. The project demonstrates full-stack web development skills, including Flask routing, Jinja templating, static asset management, and structured multi-page website design.

## Features

- **Home Page:** Overview of the shop, pet care tips, featured products, and promotions.  
- **Services Page:** Details grooming, training, and veterinary services, with pricing, testimonials, and FAQs.  
- **Pets for Adoption Page:** Lists adoptable pets with photos, descriptions, and adoption instructions.  
- **About Us Page:** Shares the shop’s history, mission, staff bios, and community involvement.  
- **Contact Us Page:** Provides a contact form, store address, phone number, and business hours.  

## Technologies Used

- Python 3  
- Flask web framework  
- Jinja2 templates  
- HTML5 & CSS3  
- Bootstrap 4  
- Static assets (images, stylesheets)
